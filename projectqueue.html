Jollibee Queue System

Arduino project with voice announcement for order number.

  • Arduino
  • C++
  • Voice

Project Overview

This project is a queue system for a Jollibee store using Arduino. It shows the order number on a display and plays a voice announcement when the order is ready.

Tools / Technologies

  • Arduino
  • C++
  • VS Code
  • DFPlayer Mini

My Role

I designed the circuit, coded the program, and tested the voice module.
